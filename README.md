# Rule-Based Chatbot

This is a simple rule-based chatbot created using Python for my CodSoft AI Internship.
As the directions provided , the chatbot responds to user inputs using predefined rules and conditions. It can answer basic questions, greet users, and can have simple conversations. If the chatbot doesn't recognize an input, it responds with a default message.

## Features

* Greets the user
* Can answers simple questions
* Uses if-else statements 
* Ends the chat when the user types "bye" or "bye!!!"

## Technologies Used

* Python
* Conditional Statements (like if ,elif, else)
* Loops

## How to Run

1. Download the project.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

python chatbot.py 

5. Type hi or hello

## sample chat

You: hi
Bot: Hi! How are you?
You: what are you
Bot: I am a chatbot made by Mantsha.
You: good morning
Bot: Good morning! "user's name"
You: bye
Bot: Goodbye!
