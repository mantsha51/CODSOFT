# Tic-Tac-Toe 

This project is a Tic-Tac-Toe game developed using Python and minimax algorithm as part of my CodSoft AI Internship.

The game allows you (player) to compete against an AI opponent. The AI uses the Minimax Algorithm to evaluate possible moves and make optimal decisions.

## Features

- Human vs AI gameplay
- AI uses the Minimax Algorithm
- calculate wins, losses, and draws
- Interactive and attactive interface

## Technologies Used

- Python
- Minimax Algorithm
- Game Theory
- Recursion (minimax())

## How to Run

1. Open the project folder.
2. Open terminal.
3. Run:

cd Task2_tictactoe
python tictactoe.py

## What I Learned

Through this project, I learned about game theory, working of algorithms, decision-making in AI, and the Minimax algorithm and game building.
