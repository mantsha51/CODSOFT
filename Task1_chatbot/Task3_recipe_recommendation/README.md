# Recipe Recommendation System

## About the Project

This project is a simple Recipe Recommendation System developed using Python and Tkinter as part of my CodSoft AI Internship.

The system allows users to select the ingredients they currently have and recommends recipes based on those ingredients. The recommendations are generated by comparing the selected ingredients with the ingredients required for each recipe, it matches the ingredients and show the matching percentage.

## Features

* User-friendly graphical interface using Tkinter
* Ingredient selection using checkboxes
* Recipe recommendations based on available ingredients
* Match percentage for recipes
* easy-to-use design

## Technologies Used

* Python
* Tkinter
* Content-Based Recommendation Technique

## How It Works

1. Select the ingredients you have from the list.
2. Click the "Find Recipes" button.
3. The system compares your selected ingredients with recipe requirements.
4. Matching recipes are displayed along with their match percentages.

## Example

If the selected ingredients are:

* Bread
* Egg
* Milk

The system will show:

* Bread Omelette (100% match)
* French Toast (100% match)
* Pancake (66% match)
